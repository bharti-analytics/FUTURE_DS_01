# FUTURE_DS_01 – Superstore Sales Analysis using Power BI

## 📌 Project Overview
This project focuses on analyzing Superstore sales data using Microsoft Power BI. The objective is to understand business performance, identify sales trends, and generate meaningful insights through interactive data visualizations.

## 🎯 Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing product categories and sub-categories.
- Analyze region-wise sales and profit.
- Understand monthly and yearly sales trends.
- Identify business performance patterns.
- Create an interactive Power BI dashboard for better decision-making.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Transformation

## 📊 Project Workflow

1. **Data Understanding:** Understand the Superstore sales dataset and its columns.
2. **Data Cleaning:** Handle missing values, check data types, and prepare the dataset using Power Query.
3. **Data Analysis:** Analyze sales, profit, product categories, and regional performance.
4. **Data Visualization:** Create charts, graphs, KPI cards, and interactive dashboard elements.
5. **Business Insights:** Identify important trends and patterns to support business decisions.

## 📈 Dashboard Features
- Sales and Profit KPIs
- Region-wise Sales Analysis
- Category-wise Performance
- Sub-category Analysis
- Sales Trends
- Interactive Filters and Slicers

## 💡 Business Benefits
- Helps understand overall business performance.
- Identifies high-performing and low-performing categories.
- Supports data-driven business decisions.
- Provides a clear view of sales and profitability trends.
